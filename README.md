# ProductionDeck releases

Downloads and the in-app update feed for [ProductionDeck](https://www.productiondeck.io).

- **Download:** the latest `ProductionDeck.dmg` is on the [Releases](../../releases/latest) page.
- **Update feed:** `https://updates.productiondeck.io/appcast.xml`. ProductionDeck checks it to offer updates in the app.

Everything here is published automatically by the release pipeline. Please don't edit `appcast.xml` by hand: it is signed, and an edited feed is rejected by the app.
